# 🔍 Image Classifier

A web app that classifies images into 1000 categories using ResNet-50.

## How it works
- Upload any image
- ResNet-50 runs inference
- Returns top 5 predictions with confidence scores

## Tech Stack
- Python, Flask
- PyTorch, TorchVision
- Pillow

## Run locally
pip install flask torch torchvision pillow
python app.py
